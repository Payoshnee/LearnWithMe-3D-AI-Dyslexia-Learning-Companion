# LearnWithMe third-party study and attribution

## Buzzphonics — reused recorded phoneme audio

Source: https://github.com/hellodeborahuk/buzzphonics

LearnWithMe includes the `a, b, c, d, e, f, g, h, i, l, m, n, o, p, r, s, t, u, w` `.m4a` recordings from `public/sounds`. The `/k/` prompt uses the source's `c.m4a` recording because the lesson teaches hard C in CAT. The source README explicitly describes the phonics sounds as MIT licensed. No Freepik icons or other Buzzphonics artwork are included.

## Open Phonics — studied, not copied

Source: https://github.com/jonajinga/open-phonics

The repository was studied for its phased, structured-lesson approach and accessibility ideas. Its README says “MIT”, but the repository did not contain a license file when reviewed on 12 October 2026. To avoid ambiguity, LearnWithMe does not copy its code, lesson text, or assets. The levels and lesson wording in this package were independently authored.
